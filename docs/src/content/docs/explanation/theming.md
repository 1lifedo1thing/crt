title: "CRT Terminal Theming"

CRT Terminal uses CSS-like syntax for theming. Themes are stored in `~/.config/crt/themes/` and selected via `config.toml`.

## Documentation

- **New to theming?** Start with the [Build Your First Theme](../../tutorials/build-your-first-theme/) tutorial
- **Quick setup:** [How to Create a Custom Theme](../../how-to/create-custom-theme/)
- **All CSS properties:** [Theme CSS Properties Reference](../../reference/theme-css-properties/)
- **Built-in themes:** [Built-in Themes Reference](../../reference/built-in-themes/) and [Theme Gallery](../../reference/gallery/)
- **Animated sprites:** [How to Create a Sprite Sheet from a GIF](../../how-to/create-sprite-from-gif/)
- **Reactive events:** [How to Set Up Reactive Themes](../../how-to/set-up-reactive-themes/)
