# Audit v0.1.4 perf rework for further regressions and add regression tests

## Objective

The v0.1.4 performance rework (PR #5, commits `750655e..62448b1`, 71 files, +10.7k/-5.6k) introduced at least four regressions, fixed in PR #6 (`fix/post-optimization-rendering-bugs`): overlay text clobbering the persistent tab-title buffer, lost X11/Wayland clipboard, an idle redraw loop (`EffectsRenderer::is_animating`), and dropped frames on surface errors. One reported bug is still open: **Copy on macOS does not reach the pasteboard**.

Do a deep review of the whole rework for further regressions, and add local regression tests that would have caught the known bugs and that pin down any new ones.

## Backlog Item Details

### Type
- [x] Bug - Production issue that needs fixing

### Priority
- [x] P1 - High (important for user experience)

### Impact Assessment
- **Affected Users**: all users of v0.1.4.
- **Common signature of the known bugs**: state that the old always-redrawing loop / per-frame rebuilds made harmless became load-bearing: dirty flags, "animating" flags, persistent-buffer ownership, handle lifetimes.
- **Expected vs Actual**: v0.1.4 should be behaviour-identical to v0.1.3 apart from performance.
