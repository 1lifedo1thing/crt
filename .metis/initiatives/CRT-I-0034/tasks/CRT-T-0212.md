# crt-update crate: release manifest parsing and install-kind classification

## Parent Initiative

[[CRT-I-0034]] In-place self-update with update notifications. Phase 2: the pure layers, with no I/O, fully unit-tested on both CI platforms.

## Objective

Create `crates/crt-update` with the two pure modules everything else builds on: parsing `SHA256SUMS` into a release manifest and choosing the asset for this platform (REQ-001), and classifying where the running binary came from so the updater knows whether it may replace it (REQ-003).

## Acceptance Criteria

- [ ] `crates/crt-update` is a workspace member with `semver` as its only new dependency (`sha2`, `tar`, `flate2` come in CRT-T-0214).
- [ ] `manifest::ReleaseManifest::parse(&str) -> Result<ReleaseManifest, ManifestError>`: accepts coreutils `sha256sum` output (two spaces, optional leading `*`), ignores blank lines and `#` comments, requires every filename to match `crt-<semver>-<os>-<arch>.tar.gz`, and errors when entries disagree on the version or a hash is not 64 hex chars.
- [ ] `ReleaseManifest::asset_for(os: &str, arch: &str) -> Option<&Asset>` and `Asset { name, sha256: [u8; 32], download_url }` where the URL is `https://github.com/colliery-io/crt/releases/download/v<ver>/<name>`.
- [ ] `manifest::compare(running: &str, latest: &Version) -> UpdateStatus { UpToDate, Newer(Version), RunningIsNewer }`; a running version that fails to parse is an error, not a panic.
- [ ] `install_kind::classify(exe: &Path, probe: &dyn FsProbe) -> InstallKind` with `InstallKind::{AppBundle { bundle_root }, UserBinary { path }, Managed { hint: ManagedHint }, Dev}` and `FsProbe { canonicalize, is_writable(path), home_dir, is_debug_build, homebrew_prefix }`. Rules and order exactly as REQ-003: canonicalise first; `Dev` if debug build or path contains a `target` component; `Managed` if under `/usr`, `/opt`, the Homebrew prefix, `~/.cargo/bin`, or the parent dir is not writable; `AppBundle` if a `*.app/Contents/MacOS/` ancestor exists; else `UserBinary`.
- [ ] `ManagedHint::{Pacman, Cargo, Homebrew, SystemPrefix}` each map to the one-line upgrade hint text (REQ-007).
- [ ] `InstallKind::can_self_replace()` is true only for `AppBundle` and `UserBinary`.
- [ ] Tests, all pure, running on macOS and Linux CI: manifest fixtures (the real v0.1.5-shaped file, a mixed-version file, a bad hash, `*`-prefixed lines, CRLF); asset selection for all four platforms and a missing one; version comparison incl. `v` prefix and pre-release tags; classification for every rule with a fake `FsProbe`, including a symlink `~/.local/bin/crt -> ~/.cargo/bin/crt` (Managed), `cargo run --release` from `target/release/crt` (Dev), `/Applications/crt.app/Contents/MacOS/crt` owned by the user (AppBundle) and not writable (Managed), `~/.local/bin/crt` (UserBinary).
- [ ] `cargo clippy --all-targets` clean; crate has a short `README`/module doc stating it does no I/O.

## Implementation Notes

### Technical Approach
- `FsProbe` is a trait with a `RealFs` impl in the crate (behind no feature; it is tiny) and an in-memory `FakeFs` in tests.
- Keep OS/arch strings as the release naming uses them (`macos`/`linux`, `x86_64`/`aarch64`); a `fn current_platform() -> (&'static str, &'static str)` maps `cfg!(target_os)`/`cfg!(target_arch)`.

### Dependencies
None on other tasks; CRT-T-0211 defines the file format this parses.

### Risk Considerations
Misclassification is the dangerous failure (replacing a package-managed binary). Every rule in REQ-003 has a test; when in doubt the classifier must return `Managed`.
